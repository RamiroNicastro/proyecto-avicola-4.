# 02 — Clientes y demanda

**Alcance:** validación de demanda del canal supermercados (~90 bocas, **no validado**), carnicería familiar y otros canales (mayoristas, HORECA, instituciones). Volúmenes, mix de productos, precios, condiciones de pago, exigencias de calidad y habilitación.

**Preguntas clave**
- ¿Qué volumen y mix compra hoy la red y a quién?
- ¿Qué habilitación exige (municipal, provincial, tránsito federal)?
- ¿Qué evidencia de compromiso existe (entrevistas, cartas de intención)?
